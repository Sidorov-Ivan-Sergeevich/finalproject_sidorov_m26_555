## Актуальность курсов

Срок актуальности кеша задаётся параметром
rates_ttl_seconds в секции [tool.valutatrade] файла pyproject.toml.
По умолчанию он составляет 300 секунд.

Если курс отсутствует или устарел, приложение предлагает выполнить:

```text
update-rates
```

Команда get-rate самостоятельно не запускает обновление через API.

## Дополнительные фильтры курсов

Две самые дорогие криптовалюты из доступного свежего кеша:

```text
show-rates --top 2
```

Курсы относительно EUR:

```text
show-rates --base EUR
```

## Отдельный запуск парсера

Эти команды выполняются в PowerShell из корня проекта,
а не внутри приложения valutatrade.

Разовое обновление:

```powershell
uv run valutatrade-parser --once
```

Периодическое обновление каждые 900 секунд:

```powershell
uv run valutatrade-parser --interval 900
```

Остановка периодического обновления: Ctrl+C.

Перед проверками, переустановкой или сборкой проекта
остановите работающий парсер.

## Логи

- logs/actions.log — журнал операций
- logs/parser.log — журнал обновления курсов

По умолчанию используется JSON-формат.
Ротация: 1 МиБ на файл, до трёх резервных копий.
