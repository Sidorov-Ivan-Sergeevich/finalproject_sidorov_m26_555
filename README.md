# ValutaTrade Hub

Учебное консольное приложение для управления виртуальным
валютным портфелем и получения курсов валют.

Автор: Иван Сидоров.
Группа: М26-555.

Приложение предназначено для учебной симуляции.
Операции с реальными деньгами не выполняются.

## Статус разработки

Создана начальная структура Python-пакета.
Модели, команды и сервис получения курсов находятся в разработке.

## Технологии

- Python 3.12+
- uv — управление проектом и зависимостями
- PrettyTable — таблицы в терминале
- Requests — HTTP-запросы к API
- Ruff — проверка и форматирование кода
- pytest — автоматические тесты

## Установка зависимостей

```powershell
uv sync
```

## Структура проекта

- `valutatrade_hub/core/` — модели и бизнес-логика
- `valutatrade_hub/infra/` — настройки и JSON-хранилище
- `valutatrade_hub/parser_service/` — получение и обновление курсов
- `valutatrade_hub/cli/` — командный интерфейс
- `data/` — локальные данные приложения
- `tests/` — автоматические тесты

## Проверка кода

```powershell
uv run ruff check .
uv run ruff format --check .
```

Рабочие данные, логи и API-ключи не сохраняются в Git.


## Запуск приложения

Основная команда:

```powershell
uv run valutatrade
```

Альтернативный запуск из корня проекта:

```powershell
uv run python main.py
```

Сейчас приложение выводит проверочное приветствие.
Команды кошелька будут добавлены на следующих этапах.

## Сборка пакета

```powershell
uv build
```

Результат сборки сохраняется в `dist/`:
архив исходников `.tar.gz` и пакет `.whl`.
