# ValutaTrade Hub

Учебное консольное приложение для управления виртуальным валютным
портфелем и получения курсов фиатных валют и криптовалют.

**Проект:** finalproject_sidorov_m26_555  
**Автор:** Иван Сидоров  
**Группа:** М26-555

Приложение предназначено для учебной симуляции.
Операции с реальными деньгами не выполняются.

## Возможности

- Регистрация пользователей и вход в аккаунт.
- Пополнение виртуального USD-кошелька.
- Покупка и продажа валют с расчётами через USD.
- Просмотр кошельков и общей стоимости портфеля.
- Получение прямого и обратного курса валют.
- Обновление криптовалютных курсов через CoinGecko.
- Обновление фиатных курсов через ExchangeRate-API.
- Просмотр и фильтрация курсов из локального кеша.
- Разовое и периодическое обновление курсов отдельным парсером.
- Сохранение данных в JSON и логирование операций.
- Обработка некорректных команд, недостатка средств и ошибок API.

## Технологии

- Python 3.12+.
- uv — управление зависимостями, запуск и сборка пакета.
- PrettyTable — таблицы в терминале.
- Requests — HTTP-запросы.
- Ruff — проверка и форматирование кода.
- pytest — автоматические тесты.

## Установка

Для работы нужны установленные Git и uv.
Проект использует Python версии 3.12 или новее.

Склонируйте репозиторий:

```powershell
git clone [https://github.com/Sidorov-Ivan-Sergeevich/finalproject_sidorov_m26_555.git](https://github.com/Sidorov-Ivan-Sergeevich/finalproject_sidorov_m26_555.git)
```

Перейдите в папку проекта:

```powershell
cd finalproject_sidorov_m26_555
```

Установите зависимости:

```powershell
uv sync --frozen
```

Все последующие команды PowerShell выполняются из корня проекта.

## Настройка API-ключа

Для получения фиатных курсов зарегистрируйтесь в ExchangeRate-API:

https://www.exchangerate-api.com/

Получите персональный API-ключ в личном кабинете.

В PowerShell выполните:

```powershell
$secret = Read-Host "ExchangeRate API key" -AsSecureString
```

В появившийся запрос вставьте настоящий ключ и нажмите Enter.
Ввод будет скрыт.

Затем выполните:

```powershell
$env:EXCHANGERATE_API_KEY = ([System.Net.NetworkCredential]::new("", $secret)).Password.Trim()
Remove-Variable secret
```

Запускайте приложение и парсер из этого же терминала.
Для нового терминала переменную окружения нужно установить заново.

Файл `.env.example` содержит образец настройки.
Само наличие этого файла не устанавливает переменные окружения.

Настоящие API-ключи нельзя добавлять в исходники, README,
`.env.example` или коммиты Git.

Для публичных запросов CoinGecko в базовом сценарии
персональный ключ не требуется. Доступность запросов зависит
от действующих ограничений сервиса.

## Обновление курсов

Следующие команды выполняются внутри приложения.

Обновление из всех источников:

```text
update-rates
```

Только криптовалюты:

```text
update-rates --source coingecko
```

Только фиатные валюты:

```text
update-rates --source exchangerate
```

Для ExchangeRate-API необходимо заранее установить
переменную окружения `EXCHANGERATE_API_KEY`.

Для реального обновления нужны интернет и доступность API.
Возможны ограничения частоты запросов.

## Просмотр курсов

Показать курсы из локального кеша:

```text
show-rates
```

Показать курс конкретной валюты:

```text
show-rates --currency EUR
```

Две самые дорогие криптовалюты из доступного свежего кеша:

```text
show-rates --top 2
```

Показать курсы относительно EUR:

```text
show-rates --base EUR
```

Получить прямой и обратный курс:

```text
get-rate --from EUR --to USD
```

## Пример работы с кошельком

Команды выполняются внутри приложения, по одной.

Сначала обновите курсы:

```text
update-rates
```

Зарегистрируйте учебного пользователя:

```text
register --username demo_user --password demo1234
```

Войдите:

```text
login --username demo_user --password demo1234
```

Пополните виртуальный USD-кошелёк:

```text
deposit --amount 1000
```

Посмотрите портфель:

```text
show-portfolio
```

Купите BTC:

```text
buy --currency BTC --amount 0.0001
```

Продайте часть BTC:

```text
sell --currency BTC --amount 0.00005
```

Снова посмотрите портфель:

```text
show-portfolio
```

Оцените портфель в EUR при наличии свежих курсов:

```text
show-portfolio --base EUR
```

Выйдите из аккаунта:

```text
logout
```

Завершите приложение:

```text
exit
```

Если имя `demo_user` уже занято, используйте другое имя
или войдите в существующий учебный аккаунт.

Пароль из примера предназначен только для демонстрации.
Не используйте пароли от почты и других сервисов.

В командах `buy` и `sell` параметр `--amount` задаёт
количество валюты, а не стоимость сделки в USD.

При покупке стоимость списывается с USD-кошелька.
При продаже выручка начисляется на USD-кошелёк.

Команда `deposit` работает только с виртуальными средствами.
